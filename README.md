# SQL-exercise-02_Aggregate-functions-and-operators


##  Project Overview
This repository contains questions and table answers demonstrating the use of **SQL Aggregate Functions** and **Logical Operators** for data summarisation and filtering.
The goal of this exercise was to develop a deeper understanding of how to summarise and analyse data using SQL with - Grouping data
- Filtering aggregated results
- Applying logical conditions to queries

The exercise includes 15 practical questions across multiple datasets:
-students
-courses
-enrollments
-salaries
-projects

##  Aggregate Functions  that are Covered in the exercise include:
- `COUNT()` – Counts rows or non-null values
- `SUM()` – Calculates total values
- `AVG()` – Computes average values
- `MIN()` – Finds the smallest value
- `MAX()` – Finds the largest value
- HAVING

  ##  Operators Covered
Logical and comparison operators used:
- `AND`,
- `=`, `<>`, 
- `BETWEEN`

 ## Learning Outcomes
After completing this exercise i am able to:
-Understand how to summarise data using aggregate functions
-Apply logical operators to filter results effectively
-Combine grouping and filtering for advanced queries
